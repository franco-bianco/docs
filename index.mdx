---
title: "Introduction"
description: "Get reCAPTCHA v3 tokens for your own site through a simple job API."
---

bapsolver produces reCAPTCHA v3 tokens for a page and its public site key. You submit a job, then read the job until it holds a token. The API supports reCAPTCHA v3 and reCAPTCHA Enterprise.

<Note>
  Use the API only for sites that you own or that you have permission to test. A token does not tell you its score. Only the site owner can verify a token, with the site's secret key.
</Note>

## How it works

<Steps>
  <Step title="Submit a job">
    Send `POST /v1/jobs` with the page URL, the site key and an optional action. The API answers at once with `202 Accepted` and the job ID.
  </Step>
  <Step title="Read the job">
    Send `GET /v1/jobs/{id}?wait=20`. The request stays open until the job finishes or the wait ends.
  </Step>
  <Step title="Use the token">
    A finished job holds the token and the browser identity that made it. Send them to your site together, within about two minutes.
  </Step>
</Steps>
